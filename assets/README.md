# Visual Assets & Mockups

This folder contains all visual documentation for the Week 3 UI/UX project.

### Directory Structure:
- `wireframes/`: Low-fidelity sketches and layout wireframes.
- `screenshots/`: High-resolution UI screen exports and final mockups.
- `user-flows/`: Flowcharts and user interaction diagrams.

*(Visual assets, flow diagrams, and screen exports are uploaded directly to this directory).*
